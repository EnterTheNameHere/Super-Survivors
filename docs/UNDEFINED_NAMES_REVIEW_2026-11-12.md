# Undefined name review — 2026-11-12

Verified against the installed `projectzomboid.jar` and vanilla Lua. Definitions
are in `editor/pz-api/library.lua`, regenerated by `tools/generate_editor_api.py`.
No undefined-global diagnostic suppression was added.

## Verified native globals

These functions exist on `LuaManager.GlobalObject` and now have typed definitions:

`getActivatedMods`, `getWorld`, `instanceItem`, `triggerEvent`, `getGameSpeed`,
`getModFileWriter`, `getFileSeparator`, `getModFileReader`, `isClient`, `isServer`,
`getTexture`, `getSoundManager`, `getDebug`, `getNumClassFields`, `getClassFieldVal`,
`getClassField`, `addSound`, `sendClientCommand`, `moduleDotType`,
`getGametimeTimestamp`.

In particular, the capitalization of `getGametimeTimestamp` is genuine. This
game-time timestamp is separate from the system clock's `getTimestampMs`.

These are native classes or nested types, with constants and selected methods
included in the editor definitions:

`TextDrawObject`, `IsoUtils`, `IsoCamera`, **`SurvivorFactory`**, `CharacterTrait`,
`BodyPartType`, `ItemBodyLocation`, `BehaviorResult`, `PerkFactory`,
`SwipeStatePlayer`, `BloodBodyPartType`, `BloodClothingType`, `ImmutableColor`,
`Mouse`, `Metabolics`, `IsoBarricade`, `CharacterActionAnims`.

`BehaviorResult` is the nested type of `PathFindBehavior2`; `Mouse` here refers
to `zombie.input.Mouse`, not the separate LWJGL class. Constructor overloads for
`TextDrawObject.new` and `ImmutableColor.new` are extracted from the JAR.
Standard Java List and BufferedReader have small hand-maintained contracts;
other referenced Java classes without supplied methods remain opaque.

## Validation

### Additional names and annotations

- Added verified `LuaEventManager.AddEvent`/`triggerEvent` signatures to the
  generated editor API. A separate editor-only declaration describes the mod's
  `on_update_group_role` event, which is dynamically registered at runtime.
- `ASuperSurvivor` in SurenderTask was a nonexistent global. The surrender
  visibility check now uses `self.parent` and the enemy's actual character;
  the distance call likewise receives the character rather than its wrapper.
- `SurvivorDialogue` was a typo for the existing `SuperDialogue` table.
  SpeakDialogueTask explicitly requires its defining file and checks the
  parent's speaking state rather than invoking a nonexistent task method.
- `AutoWorkTaskTimeLimit` was local to AI-Manager, unavailable in the context
  menu. Guard orders now use a local 300-update limit matching that manager.
- `attempts` in AttemptEntryIntoBuildingTask is now obtained locally from
  `getWalkToAttempt` and shared by the diagnostic and retry comparison.
- `coord` in unloaded-member UI handling now reads the intended `coords` local.
- Four out-of-scope `worldobjects` reads were unused submenu-header targets;
  they now explicitly pass nil. Valid handler parameters remain unchanged.
- Removed the nonexistent argument from `group:getBounds(baseBounds)`; the
  getter takes no arguments.
- Documented `table.load` as returning `table|nil`, and corrected the
  `kvtablesave` parameter annotation to `fileTable`.

Behavioral tests cover sequential dialogue and speech waiting, surrender using
the actual enemy character, and reload attempts for an unloaded member with no
coordinate record. No stub definitions were invented for these local variables.

The editor library passes LuaLS checks. All 108 runtime Lua files compile under
Lua 5.1. Regression checks cover movement slowdown sources, pursuit target kind
and companion behavior, and the held weapon passed by all three gun tasks. These
are mocked Lua checks, not an in-game pathfinding/combat/farming validation.
